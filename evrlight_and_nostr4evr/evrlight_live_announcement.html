The EvrLight Live Demo Release 2026-09-28

The announcement of EvrLight's first application code release and live demo was made on Sept 28th 2026 in the #news channel of the community Discord server. It is transcribed here.


!!!*** EvrLight is live on testnet ***!!!

I am very happy to announce that today I am publicly releasing the first EvrLight application.

This is code which I have wanted to see for over 3 years. It has been many months of work to create the software and the infrastructure which it requires.

I believe that EvrLight fundamentally changes how we should think about Evrmore and the future. EvrLight uses Bitcoin Lightning to enable the buying and selling of tickets, coupons, NFTs, and real-world tokenized commodities and securities. EvrLight is like WooCommerce for buying any digital asset paid for using Bitcoin Lightning or using Dollars via Block Inc's CashApp.

EvrLight doesn't need exchanges, centralized or otherwise. EvrLight is much closer to the original Ravencoin vision (as I understood and embraced it) than the exchange-based speculative trading which has dominated the blockchain digital asset markets since Ravencoin was founded.

With EvrLight, buying an Evrmore asset is a super-simple 3-step process:

    1) click, 2) enter a number, 3) scan


In a bit more detail:

    1 You click on a link you found for something tokenized which you wish to purchase.
    2) A dialogue pops up asking you how many you want to buy at the posted price. You enter the number.
    3) A QRCode invoice pops up. You can pay in Bitcoin with a Lightning wallet or with Dollars using Block Inc's CashApp
    -In about 3 seconds typically, if your payment went through and the asset was available, you are given the contract address as your receipt from the explorer mempool. That's it ! You are done !
    -In another 2 minutes typically, the contract and product delivery sweep transactions will be confirmed by the miners proving that product delivery is complete.


The merchant or individual who sold the asset is always paid in Bitcoin Lightning satoshis

EvrLight is primarily a back-end technology for integration into social media applications and other graphic user interfaces. But it includes a minimal web-based dialogue so that it also works stand-alone as done for the EvrLight demo. When run from inside a Nostr app, it would already know your identity from your login, from which it would know your keypair and automatically calculate the Evrmore address to which the purchased assets should be delivered. In standalone mode, it asks you for your Evrmore address when it asks you to enter the quantity you want.


More details are available in the EvrLight whitepaper available at https://github.com/EvrmoreOrg/EvrLight

In its current state, I am publishing EvrLight code in two Github repositories. Read the README files.

    https://github.com/EvrmoreOrg/EvrLight_buyer - Everything you need to create clickable links for asset buyers.
    https://github.com/EvrmoreOrg/EvrLight_seller - The code you will need to run on a server in order to sell assets. You also need a Lightning node.


I have the code from those two Github repositories running live on testnet as a demo.
If you want to try the demo, do the following:

    1) Download the phoenix testnet Android mobile lightning wallet from HERE
    2) Side-load install and open the Lightning wallet on you phone. Select "Receive" near the bottom. Swipe the QRCode left to get an on-chain address.
    3) Go to the bitcoin testnet3 faucet at HERE and enter your address
    4) Wait for Lightning satoshis to show up in your phoenix wallet
    5) On any computer or phone go to HERE


The demo is on testnet where nothing costs any real money, but please don't drain all the assets.
EvrLight is designed to be robust against spam and denial-of-service attacks once it is deployed on mainnet.
